# Folder Structure Guide

| Path | Purpose |
|------|---------|
| src/app | Routes, layouts, metadata |
| src/features | Feature UI modules |
| src/components | Shared UI, header/footer, form-engine |
| src/services | App services (home, tools, search, platform) |
| src/tool-engine | Runtime, registry, logic, configuration |
| src/data | Seed data |
| src/theme | Design tokens / theme provider |
| tests | Vitest + Playwright |
| docs | Documentation |
| scripts | CI quality and release scripts |
